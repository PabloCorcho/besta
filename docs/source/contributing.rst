Contributing and contact
========================

BESTA is an open-source project, and we warmly welcome contributions from the community. Whether you're fixing a bug, improving documentation, or adding a new feature, your help is much appreciated!

- **Report Issues**

Share feedback, request features, or report bugs by opening a new `issue <https://github.com/pablocorcho/besta/issues>`_ on GitHub.

- **Contribute Code**

If you’d like to contribute code, use the standard GitHub fork-and-pull-request workflow:

1. Fork the repository on `GitHub <https://github.com/pablocorcho/besta>`_.
2. Create a feature branch for your change.
3. Add or update tests and documentation when relevant.
4. Open a pull request against the main repository and describe the motivation for the change.

For documentation changes, please keep the Sphinx pages in ``docs/source`` synchronized with the public API and tutorial workflow.


- **Contact**

If you have questions or need specific help, do not hesitate to send an email to <p.corcho.caballero@rug.nl>.
